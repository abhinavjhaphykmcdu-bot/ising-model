# 2D Ising Model Simulation
Developed as part of the *Statistical Analysis of Physical Systems using Monte Carlo and MCMC* program (PaAC x QCG Open Projects 2025, IIT Roorkee).

## Overview
This project implements a Monte Carlo simulation of the 2D Ising model using the Metropolis algorithm to study phase transitions and spin configurations.

## Key Features
- Metropolis Monte Carlo algorithm
- Periodic boundary conditions
- Temperature-dependent simulation
- Visualization of spin configurations

## Concepts Used
- Statistical Mechanics
- Monte Carlo Methods
- Markov Chains
- Phase Transitions

## Tools & Libraries
- Python
- NumPy
- Matplotlib

## Results
The simulation demonstrates temperature-dependent behavior of spin alignment and phase transition characteristics.

## How to Run
1. Open the Jupyter notebook
2. Run all cells
3. Adjust temperature parameter to observe different behaviors
